# Individual Projects
 
**Three projects in this repository:**

**Stock Financial Predictor**: A React + TypeScript dashboard backed by a Python FastAPI server that predicts stock price direction for long-term investing, swing trading and day trading, combining a gradient-boosting model and an LSTM neural network, with walk-forward backtests showing how accurate each model really is

**Earthquake Predication Model**: Created by splitting data from a database with Earthquake data from the past, and using a neural network to predict the accuracy of the next earthquake

**Text Summartizer**: Created by using a NLP (Natural Language Processor) through the use of the nltk libraries
